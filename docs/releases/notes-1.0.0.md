# 寒淋笔记 1.0.0

HanLin-Notes 1.0.0（中文名：寒淋笔记）是笔记库与文档页重做后的首个 1.0 版本，数据格式不变，旧库可直接打开。

## 更新内容

- **笔记库与文档页重做**：重新组织顶栏、主题导航、笔记卡片网格、独立文档页和六类笔记的编辑区；单击打开，返回保留选择，支持批量点选与拖拽。
- **暖色浅深主题**：三栏、编辑预览、菜单、弹窗和安装界面统一为暖白珊瑚风格，窗口、托盘与 EXE 换用多尺寸「记」字图标。
- **设置四页**：「常规／外观／数据／关于」，保存统一写入，安装与设置沿用 HanLin 系列共用向导。
- **导入自动去重**：同一个包导两次不会出现两份，跳过条数写进完成提示。
- **查找重复笔记**：按正文判重，每组默认保留最早一条，其余勾选后移到回收站。
- **产品名**：中文名统一为「寒淋笔记」，窗口、托盘、开始菜单和安装界面同步；EXE 与安装包文件名保持 HanLin-Notes，现有安装可直接升级。

## 安装

1. 下载 `HanLinNotes-1.0.0.exe` 运行。
2. 默认安装到 `%LOCALAPPDATA%\Programs\HanLin\HanLin-Notes`，作用于当前用户。
3. 升级旧便携版时，选择原来的程序文件夹，笔记随原目录使用。

也可以从 Windows「设置 → 应用」卸载，程序旁的 `Data` 目录会保留。

## 数据位置

`Data/` 在程序文件夹内：`library.json`（主题与笔记元数据）、`notes/*.md`（正文）、`attachments/`（图片附件）、`settings.json`（设置）。覆盖安装与卸载都不动这里的文件。

## 校验

资产包括 `HanLinNotes-1.0.0.exe` 与 `SHA256SUMS.txt`，可执行 `sha256sum -c SHA256SUMS.txt` 核对。

> 早期误标为 0.6.0 的版本内容与本版相同，版本号已更正为 1.0.0。请下载本页资产。
